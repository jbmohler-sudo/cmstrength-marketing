**Title:** "What Is Adaptive Powerlifting Programming?"
**Category:** The Adaptive System (CORNERSTONE — the anchor).
**Intent:** Informational/definitional head-term + commercial. The rank-for-it authority hub.
**Primary keyword:** "adaptive powerlifting programming" (fits §6 "keywords to own"). INFERENCE only.

**Internal-link role:** HUB. Links OUT to the Adaptive spokes (Autoregulation, Readiness
Scores, RPE for Powerlifting, TM vs 1RM vs e1RM, Bad-Day Adjustments, Deload vs One-Day).
Those link back. Cross-link the joint-load post (`joint-load-management-mrjv`) for the
CLM/joint layer.

**Product CTA:** Start free trial (Bench Specialization or SBD) — "let the program adapt to you."

**Outline (2,000+):**
1. **Hook:** Fixed-percentage programs stop working. Recovery varies day to day — the
   program that doesn't account for it eventually breaks.
2. **Define adaptive programming:** what it is and what it is not (vs. static 5/3/1-style
   spreadsheet training).
3. **The 5 adaptation levers** (map each to the real engine):
   - Readiness score → ±5% daily load adjustment
   - RPE as the intensity governor (1–10 scale)
   - Training max vs 1RM vs e1RM (Epley) — how TM updates
   - Joint-aware CLM rotation / per-joint MRJV (cross-link joint-load post)
   - In-session substitution & coaching (missed-rep / weak-point exercise swaps)
4. **Session walkthrough:** show how one bad night of sleep changes the top set day to day.
5. **Why it matters most for masters:** recovery variability after 40/50 (cross-link Masters).
6. **Honest limits:** what adaptive programming can and cannot fix.
7. **CTA** to the app.

**Guardrails:** only claim what the engine does; no invented outcomes. Fold-in note: the
old standalone topic "percentages needing autoregulation" lives inside the Autoregulation
